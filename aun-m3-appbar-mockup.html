What it costs, honestly

This is a real restructure, not a setting. Each tab's content has to move from a plain list into slivers so the title can react to the scroll.

  • Settings and Support — one list each. Straightforward.
  • My Devices — three separate lists behind loading, empty and error states. All three have to move, and all three need re-checking.
  • Home stays exactly as it is. Its greeting is content, not a label, so it should keep scrolling away entirely.

Worth doing if you want the three tabs to feel like one app. Not worth rushing before the Play Store submission — nothing about it is a fix.
